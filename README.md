# Flutter Riverpod App
This app is a simple post viewer built with Flutter and Riverpod. It fetches posts from a public API, shows them in a clean list, and uses Riverpod to manage loading, error, and data states.

<h3>Technologies and Dependencies Used</h3>
<ul>
🔹 Flutter<br>
🔹 Riverpod<br>
🔹 HTTP<br>
🔹 JSONPlaceholder API<br>

</ul>

<h3>Features</h3>
<ul>
✅ Fetch Posts: Load posts from a public API.<br>
✅ Refresh Data: Refresh the list using the refresh button.<br>
✅ Clean UI: Display posts in a simple, scrollable list.<br>
✅ State Management: Handle loading, error, and data states with Riverpod.<br>
</ul>
